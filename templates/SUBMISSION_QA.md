## Pre-submission checks — HARD for READY (any FAIL blocks)

- [ ] Current official contest schedule/entry terms/FAQ checked; date and links retained
- [ ] Public transport open data source within current official conditions truly drives core experience
- [ ] Source license, API terms, intended use, derivatives, redistribution, caching, attribution reviewed for exact deployed bundle
- [ ] No API token, private contact info, personal transit/medical/location history or forbidden raw feed leaked in public repo or shipped JS
- [ ] Public app independently reachable without paywall and usable free, in logged-out/private browser
- [ ] Contact route for questions about app exists and is visibly offered; no responsibility sent to OD data providers
- [ ] Applicant can lawfully submit own work; copyrighted third-party assets appropriately licensed
- [ ] Specified developer portal, account/entry registration and required submission fields confirmed; submission has not yet been required
- [ ] App content does not imply it is an officially endorsed public authority tool
- [ ] Deadline and post-deadline changes policy acknowledged
